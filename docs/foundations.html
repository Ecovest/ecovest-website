Deep liquid green

Every colour is built in OKLCH, so each step looks evenly lighter or darker. The main brand green is a deep emerald. Leaf is the brighter logo green, used for highlights on dark backgrounds. 04 · Icons

Hugeicons only

Every icon on the site comes from Hugeicons, using the free Stroke Rounded set (4,600+ icons) at a 1.5px stroke. No other icon library, and no emoji or text symbols standing in for icons. These are rendered live from the official package.
